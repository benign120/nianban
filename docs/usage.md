# 念办使用说明

## 安装

从 Releases 下载 `nianban-0.6.0.apk`。已安装念办的手机直接覆盖安装，不要先卸载。Android 8.0 或更高版本；APK 提供 arm64-v8a 与 x86_64 库。

## 个人任务

支持“明天下午三点修改简历”“每天晚上十点读书二十分钟”等表达。“明天买牛奶”仅入清单，不自动补提醒时刻。歧义时间需确认。常见表达和手动添加可离线使用；复杂表达需在手机设置中填写自己的 DeepSeek API Key，且账户有可用余额。密钥通过 Android Keystore 加密保存在手机，不随任务导出。

已保存的通知由 Android 调度，实际送达受通知、精确闹钟权限和系统后台策略影响。“工作日”为周一至周五，未接入节假日调休。时间采用北京时间。

## 搭子

两人安装同一新版，进入“搭子”创建昵称。一方生成邀请码，另一方输入申请，接受后建立关系，再各自选择愿意共享的任务。设备凭据自动生成，不通过聊天或邀请码分享。

提醒同任务间隔至少 6 小时，每人每日互动最多 10 次。对方不能代为修改或完成任务。打开应用或刷新后同步，没有后台即时推送。原话、录音与密钥不随搭子同步发送；复杂模型理解的输入会独立发送至 DeepSeek。

预编译 APK 使用有限开发内测环境，存在额度、有效期和稳定性限制。自行构建请部署自己的搭子服务并配置地址。卸载或清除数据会丢失本机任务和搭子身份，目前没有换机找回。

## 小组件

“设置 → 添加桌面小组件”，或通过系统桌面的小工具菜单添加“念办 · 今日清单”。小组件打卡先写本地，下次打开 App 联网后同步给好友。当前尚待不同手机和桌面的实际显示与点击验收。

## 可选微信入口

详见 `weixin/README.md`。需要电脑在线，手机与电脑在同一局域网，打开 App 后拉取。微信回复“已记下”表示电脑保存成功；手机成功导入后才设置本地提醒。不要公开连接码、电脑证书私钥或 `.local/` 目录。
