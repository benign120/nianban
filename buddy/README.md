# 念办监督搭子服务

CloudBase 普通 Node.js 云函数，入口 `index.main`。使用 `@cloudbase/node-sdk`，由环境内置身份访问文档型数据库。

## 自行部署

1. 在自己的 CloudBase 环境建立集合 `nianban_buddy`，客户端权限设置为 `ADMINONLY`（无权限）。
2. 在本目录运行 `npm ci`，将 `index.js`、`core.cjs`、包文件及依赖上传为普通云函数，入口 `index.main`，使用 Node.js 20 或更高版本。
3. 将 HTTPS 网关 `/buddy` 关联到函数。手机通过原生 HTTPS 请求，函数自行验证 Bearer 设备凭据。客户端数据库权限保持禁止访问，不在日志打印凭据与任务正文。
4. 将接口地址写入 `android/buddy-config.json` 后构建自己的 APK。
5. 通过独立测试身份验证关系确认、共享、打卡、撤回、解除关系和错误权限，再在手机验证。

免费环境的套餐、额度、执行超时、域名限制与续期条件以账号当时页面为准。本项目验证时免费函数执行超时固定为 3 秒，未使用付费升级。

## 边界

设备凭据随机生成，云端只保存其散列标识。每人一位搭子，最多共享 10 项任务，邀请码 24 小时有效。邀请需要双方确认。

仅接收任务名称、日期时间、重复规则和完成记录，不接收录音、原话或模型密钥。手机号、密码和换机找回尚未实现。

数据位于 `private_state` 文档的 `payload` 中，使用事务更新。当前实现为最多 50 个身份、单文档 750KB 的小范围内测方案；有注册和操作限流，不适合直接大规模公开运营。前台同步，没有后台消息推送。

参考：https://docs.cloudbase.net/service/access-cloud-function
